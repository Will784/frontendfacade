# Guía de commits — Frontend

Descomprime el zip y copia su contenido dentro de tu repositorio clonado.
Luego ejecuta los bloques **en orden**: cada uno agrega solo los archivos de esa parte,
así el historial queda con commits claros.

## 1. chore: initialize React + TypeScript project with Vite

```bash
git add .env.example \
  .gitignore \
  index.html \
  package-lock.json \
  package.json \
  public/favicon.svg \
  src/main.tsx \
  src/styles/global.css \
  src/vite-env.d.ts \
  tsconfig.json \
  vite.config.ts
git commit -m "chore: initialize React + TypeScript project with Vite"
```

## 2. feat: add API client and services layer

- ApiClient adds the JWT token and turns every failure into a friendly AppError
- AuthService, HotelService and SessionStore classes
- TypeScript models that mirror the backend responses

```bash
git add src/api/ApiClient.ts \
  src/api/AppError.ts \
  src/models/auth.ts \
  src/models/hotel.ts \
  src/services/AuthService.ts \
  src/services/HotelService.ts \
  src/services/SessionStore.ts \
  src/services/index.ts
git commit -m "feat: add API client and services layer"
```

## 3. feat: add login, registration and protected routes

- AuthContext keeps the session and logs out when the token expires
- Forms with hints, character counters and live password checklist
- Same limits as the backend; errors shown in friendly Spanish messages
- ErrorBoundary avoids blank screens or technical details
- Base layout and styles

git add src/App.tsx \
